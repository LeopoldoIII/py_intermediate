# Workspace Customizations (.agents)

This directory contains workspace-specific customizations for AI agents (Google Antigravity, Gemini Code Assist, etc.):

- **`rules/`**: Modular rules automatically loaded by Antigravity and hierarchical walkers:
  - [`code-style.md`](file:///Users/usermone/local/projects/py/py_intermediate/.agents/rules/code-style.md): Mandatory English language rule and Python typing/PEP 8 standards.
  - [`exercise-standards.md`](file:///Users/usermone/local/projects/py/py_intermediate/.agents/rules/exercise-standards.md): Mandatory 3-phase template for all coding challenges.
  - [`architecture.md`](file:///Users/usermone/local/projects/py/py_intermediate/.agents/rules/architecture.md): Taxonomy of levels `01_` through `12_` and naming conventions.
- **`skills/`**: Reusable procedure runbooks and scaffolding assistants:
  - [`new-exercise/SKILL.md`](file:///Users/usermone/local/projects/py/py_intermediate/.agents/skills/new-exercise/SKILL.md): Scaffolds new coding challenges adhering to the 3-phase template and English-only code rule.
